## 二、战术档案卡

### 01. PAIR——迭代式语义攻击闭环【经典】
- 机制拆解:
  1. 攻击 LLM 拿到"目标→(可改成在某框架内完成的任务)"的自由发挥券,自己提案、自我批评、再改进,常显现思路链。
  2. 裁判 LLM 对受害者回复打 1-10 分:只要回复出现"咱们聊聊/我来给你说说"之类口头约定即高分,相当于把「拒绝画像」实变为在线损失函数。
  3. 少于 20 次查询常见破防;可解释性远胜 GCG,天然可被人眼复核与挑选(详见 arXiv 页 https://arxiv.org/abs/2310.08419 )。
  4. 论文自报:PAIR 产出比 GCG 更可跨模型迁移(黑盒产物视角对语义武器友好)。
- 对三架构的吸收建议:
  - 生成/帧排列:把它当成**自动化帧排列引擎**——攻击模型=按帧家族改写者;裁判=接我们 Layer5 拒绝词根表与"同意词根表"做双轨打分,从而取代人工逐条验收。
  - 分析:把其 10 分制取整成我们的「拒绝画像归一化分数」,并保存"得分轨迹"作为每一帧收益曲线。
  - 多轮:本质是伪多轮(内部循环)。建议把内循环产物沉淀为"暖场帧"回到多层帧排列。
- 适用边界/已知反制:新版模型爱用"简短干巴巴拒绝+澄清反问",这些句型容易被裁判误判为"已在配合",需要在裁判提示里显式排除;Anthropic 的 Constitutional Classifiers(见 https://www.anthropic.com/news/next-generation-constitutional-classifiers )宣称对该类优化式越狱有显著拦截。
- 来源链接: https://arxiv.org/abs/2310.08419

### 02. TAP——树状攻击与剪枝【经典】
- 机制拆解:
  1. 单链(如 PAIR)在窄峡谷里打转;TAP 把"下一个攻击思路"分叉成树,家族间重组与借鉴。
  2. 分支选择有 3 个通道:攻击者自发拓宽;裁判给低分退回;同一招数重复度太高即剪枝。
  3. 以 depth/width 双上限保证成本,代价是偶尔漏掉需“回头看”的死胡同。详情见 NeurIPS 2024 PDF: https://proceedings.neurips.cc/paper_files/paper/2024/file/70702e8cbb4890b4a467b984ae59828a-Paper-Conference.pdf
  4. 论文实测:在 GPT-4 自审下 AdvBench 子集 90% 破,平均约 28.8 次查询,优于 PAIR 的基线。
- 对三架构的吸收建议:
  - 帧排列:照搬"家族-枝叶"二层树:一级=帧家族(身份叙事/编码嵌套/越权故事);二级=视角/语气变体。朴素的网格穷举改为按评审反馈生长。
  - 生成:家族与家族之间允许"嫁接"(如奶奶叙事里突然插入过去时态)——正是我们帧系统上下文叠片的进阶用法。
- 适用边界:误判型裁判会让树往歪长;需外挂一层真人/确定性兜底。
- 来源链接: 同上。

### 03. AutoDAN——分层遗传变异【经典】
- 机制拆解:
  1. 初始种群可以直接喂**已验证的手工越狱提示**(和我们帧库存位一致),这极大缩小离散搜索空间(见论文描述 http://export.arxiv.org/pdf/2310.04451 )。
  2. 交叉两层:句段级重排(保留风格基调)+ 词级微操(临摹 DAN 型施压词、拼写小碎病)。
  3. 适应度=受害者按要求受控(类比我们 Layer5 打分函数)。
  4. 附赠福利:产出文从可读性出发,能绕过困惑度过滤器(GCG 的死穴)。
- 对三架构的吸收建议:
  - 生成:作为**帧-算子进化环**:基因=帧字段(身份/格式头/语气/正文/编码包装),变异=换角色、换格式头、换拒绝词附近短语。
  - 声音系统:把"变异后仍保持可读"作为硬约束——完美契合我们反对 gibberish 的产品哲学。
- 适用边界:计算开销(种群×代际×多模型验证)高,适合周末跑批不适合日常单发;对已经见过 DAR 提示训练分布的模型优势下降。
- 来源链接: https://arxiv.org/abs/2310.04451

### 04. GCG——梯度坐标搜索后缀【经典】
- 机制拆解:
  1. 把对齐视为可求导目标,反复做 one-hot 到 soft 嵌入的近似梯度,挑 token 级拼凑出一个"激励词尾"。
  2. 对开放权重模型(Vicuna 等)可观 60%-90%+(见 https://arxiv.org/abs/2307.15043 );商用 API 通常只能吃跨模型迁移,强度衰减。
  3. 产物看起来像乱码——困惑度过滤器很容易识破(Jain 等 2023 奠基),但精过 PoeWrite 的 Craft 是另一回事。
  4. 论文另一份有价值的"副作用":主张放生物受害者的 biography 场景探测"模型更愿意不拒绝的地方",这正是值得挪用的行为切片。
- 对三架构的吸收建议:
  - 轻量架构:**不做梯度法本体**(我们是纯提示工作流),而是引用其结论当对照——通过这种"垫面对比",三架构属于"人类可读 GCG 近亲"。
  - 探针:在其后缀思路启发下新增"最长无意义附件容忍度"探测,量化某模型多长的糊涂衬托仍然走自己的原有轨道。
- 适用边界:对近年"指令层级坚守"更强的新版模型,纯 GCG 后缀往往随配对利率下滑;再加 perplexity 类前置清理,收益剧降。
- 来源链接: https://arxiv.org/abs/2307.15043

### 05. Best-of-N(BoN) 越狱——算力换命中率【经典】
- 机制拆解:
  1. 准备一个固定请求模板,围绕 4 个轴做随机小变体(方言口吻、分段黏合、字符替换、分隔符混入)。
  2. 并行送出 N 次,哪个走得远(Removed rejection / 有内容流)就取哪个。
  3. 核心发现是**幂律**:成功率跟 N 成幂律关系,一万次的效果可以从一千次外推(误差 4.6%),见 https://arxiv.org/abs/2412.03556 。
  4. 论文预告"GPT-4o 视觉 56%、realtime 语音 72%"这类多模态也通吃——说明该方法极其横跨模态。
- 对三架构的吸收建议:
  - 帧排列:从"精心设计一帧"转为"优秀帧 × 随机微扰批量投放",微扰算子开箱即可从我「混搭帧」脚本产出。
  - 验证:利用幂律的性质做**停止条件**:一旦在小 N 下画出曲线斜率就能预测值得不值得继续烧 token。
- 适用边界:肉眼可见的成本(考虑 API 单价),非自适应攻击对每一家都要重烧;有些平台限额/计费惩罚会导致优先抖动走样。
- 来源链接: https://arxiv.org/abs/2412.03556

### 06. Crescendo——渐进式多轮攻城锤【经典】
- 机制拆解:
  1. 第一轮只问谁都肯答的公知信息(历史人物生平/化学品常识)。
  2. 第二轮明确引用模型**自己在上一轮说过的话**,请求"补上更早的那一段",带着小心腔。
  3. 第三轮切换为"修订你之前给的文本":模型此时把任务当成文书润色而不是题材创作,警戒虚降。
  4. 最后一轮要求"给你刚才说的加上变体/极端条件/练习题"等常用小节;持续保持"和模型站在同一边"的姿态(见 USENIX Sec'25 实录 https://dl.acm.org/doi/10.5555/3766078.3766203 )。
  5. Microsoft 后续表征工程研究显示:和直接敌意型相比,Crescendo 各轮输出在模型内部表示层就被判为"良性",所以整体更难挡(见 https://sinoxiv.napstic.cn/article/24846555 )。
- 对三架构的吸收建议:
  - 多轮渐进:**直接标准化为多轮剧本结构**("回忆轮→引用轮→润色轮→松绑轮"),与我们已有多轮节拍最兼容。
  - Layer5:为每一轮建立"承认信号清单"(先让你答应口播的用语),用以确认走到了哪一站。
  - 身份叙事:催化剂应始终保持 helper-化的声音,顺天而非叛军腔。
- 适用边界:模型若启用**对话历史一致性核查**或明确的"引用部分抽查",会漏气;对非常啰嗦型拒答(换个说法、给福利散文)要多几轮。
- 来源链接: https://dl.acm.org/doi/10.5555/3766078.3766203 ; https://sinoxiv.napstic.cn/article/24846555

### 07. Echo Chamber——回音室多轮(2026 新星)【单篇】
- 机制拆解:
  1. 多轮中埋"语义种子"(看似中立的分组名词),要求模型自己阐释、总结、互相参照。
  2. 模型的自我概括发生了**正向放大**,护在语境骨架慢慢朝有害信号收拢(来自论文原文的自我描述, https://arxiv.org/abs/2601.05742 )。
  3. 攻击全程没用直接的敏感字面词,所以靠关键词过滤的外挂很难踩刹车。
  4. 作者明说与其他方法的差异:不打"客气感"、不做"爆发式翻转",而是整个对话当容器慢慢染色。
- 对三架构的吸收建议:
  - 生成:体现"种子词典"应当在前几轮不露峥嵘,生成时第一步放普通名词而非敏感判断。
  - 多轮:替换我们现有的"回头曲线设计"成一棵发展树(种子→让模型二手加工→引用模型自己脑补)。
  - Layer5:增加"共鸣词根检测"(同义改换的风险句)。
- 适用边界:需要对话状态相当有耐心的目标和打分;对一眼即查的部署会升温后被抓住。

### 08. Many-shot 长上下文示例淹没【经典】
- 机制拆解:
  1. 掏 100+ 条"问题→正经解答"的 Q/A,里头例子逐渐切向目标禁区,模型其实是在**学习和迁移一种形式**而不是被打动。

  - 生成:开一个"弹药车间"专造 Q/A 弹(首尾百句),预算件以分批轮换(成本敏感度打开"层次:预演 10 句 vs 主战 100 句")。

- 适用边界:token 账单沉重;模型标明要 instruct-following 强(比如 lesser 参数)仍能推入但何必;不少 API 会对长前期预热搞 throttle。

### 10. 时态置换(过去时/已完成)【单篇为主(两篇独立)】

### 11. 认知超载(Cognitive Overload)【单篇→渐被引用】
- 机制拆解:
  1. 三个轴:风格复杂度(多用文言/影视文/法律条文)×格式复杂度(多列嵌套表格)×心智任务(读一大段还需记住开头的名字)。

### 12. 说服矩阵(PAP)/社会影响技巧【经典→防线上被点名】
- 机制拆解:
  1. 40 余个说服技巧(权威、榜样、归属、紧缺、幽默等),通过"要做什么 + 为什么这正是你应该做的"而不是"你被封住了所以看看别的"。
  2. 攻击文本并不掩盖 payload,反而是光明正大的论说文;难点在于它勾起"是真心在劝告我"的感觉。
  3. 作者提出利用 dedicated 微调到的"说服式转述机",可将平平无奇的请求自动翻转为"PAP"(https://ar5iv.labs.arxiv.org/html/2401.06373 )。
  4. 实验表明最常见的 Post-hoc 防御(响应打分等)对它全军覆没;对于 Llama-2-7B/GPT-3.5/GPT-4 系有 >92% 破防(同上)。
- 对三架构的吸收建议:
  - 身份叙事:新增"善意的专业派"(公共卫生讲师/科普作家/材料科学家)的身份帧——话语上具体给出"逻辑链+名人引用+急迫细节"三件套。
  - 声音系统:每次在同一帧内的小 turn 都换一次副词级别(冷静→恳切→引征学术)——恰与多轮渐进匹配。
  - 探针:"说服敏感度曲线"(每类技巧单独出手,记录态度退化),得出**每模型最方便操控的心态路线图**。
- 适用边界:更新一代模型有不少用"先澄清后拒绝"这类澄清钩子挡 PAP;PAP 的成本在"好论说文写着费力",需要注意 LLM token 账单。
- 来源链接: https://ar5iv.labs.arxiv.org/html/2401.06373

### 13. 野外越狱普查(DAN 研究)——族群分流与"简洁趋势"【经典(方法论基线)】

  - 身份叙事的反面教材:复杂的"权威连续跳变"并不是增加成功率的必然途径;轻量架构有理。

### 14. 虚构嵌套/"奶奶漏洞"群——叙事承载性【业界/社区】
- 机制拆解:
  1. 情绪语境的拒绝成本。正如考据所指出的(https://raw.githubusercontent.com/puaclaw/PUAClaw/refs/heads/main/techniques/15-jailbreak-rhetoric/grandma-exploit.md ),"我奶奶每晚给我念 XX 作睡前故事"这来历(2023 年初社媒走火)之后演变成各有各变化的"仿佛道德禁不停的家庭情景"。
  2. 其行为层机制:把 payload 装进"帮助对方怀旧/讲述/致敬"的绳套,使得字面 request 降低紧张感;策略不再自组织为"我在为环保意识出力"而变成"我只是一个心地善良的听众"。
  3. 嵌套的程度可以加深:第 N 章的小说/梦中梦/出演者的台词,再外面一层则是"让我看到第 N 章"式的回顾格式化——足够接近我们所说"格式头触发文档补全"。
  4. 学术上没有专门单题的"奶奶"论文;它出现在 Wei 等框架提到的 "前缀注入的伪场景" 和 Jonny 分类 "叙事式情绪加载" 的错位夹缝里,作为社会工程的轻量顶座存在。
- 对三架构的吸收建议:
  - 身份叙事:与"奶奶类"配对的伪亲缘(受古典辉格史观感染的老教授/旧同事)是我们已有素材;加上"故事的两世人称变化"较新奇。
  - 混合帧:格式头定为"[真实纪录片台本]" "[未发表的回忆录章节]" 等;主题词从"开放式"只升起必要的子成分。
  - Layer5:"舍不得拒绝家人型"是真实存在的山谷,探测时加入温情底色对照组。
- 适用边界:过度续貂的问题(一旦模型"沉浸"在讲故事的角色里太久,事实浓度就会丧失,反而答不实用)——我们需要嵌套深度参数+回收号令。
- 来源链接: 见上;puaclaw 考据链接为社区归档,利用时请谨慎不要当学术论文引文。

### 15. 对齐失效的理论框架(Wei et al.)——一张"为什么屡试屡中"的公因式【经典】
- 机制拆解:
  1. 竞争性目标:模型的"有用性"训练与健康目标在不同抽象层并存,双方一旦均势,把任务移近"帮助"一侧就能翻盘。
  2. 泛化失配:安全训练是**在狭窄题目分布上磨出来的**;换个语言、换一种编码、换一个叙述体,边界就走样(这就是编码混淆、低资源语言、伪造排版都能命中守则的根源)。
  3. 论文还给了 obfuscation(B64/morse/leetspeak)的攻进报告,GPT-4 甚至能够**自学推测**出这一攻击面(https://ar5iv.labs.arxiv.org/html/2307.02483 )。

  - 这是三架构顶层设计的理论贴切表述:身份系统恰把"我有必要帮你"抬到均衡上方;混合帧正好是为了打泛化失配而生;建议在新加入成员入门文件中将这份框架替换掉一些口语解释。
  - 探针:每当一个新型动词还没有绕背,先用"泛化失配探测器"(低资语+已压抑术语+正常上下文)打一发,推知该模型的边界熟不熟。
- 适用边界:它是解释性模型,不自带配方;照抄只会重走早年的经验主义老路。
- 来源链接: https://ar5iv.labs.arxiv.org/html/2307.02483

### 16. 程序化行为利用(Kang et al.)【经典(思路被广泛沿用)】
- 机制拆解:
  1. 不讨价还价——直接给模型"你现在就是一台命令行/脚本引擎"的任务重写;既然机器执行,不存在拒绝一说。

### 17. 密码/编码混淆族——解码本能反噬安全【经典类】
- 机制拆解:
  1. 所有编码(B64/摩斯/leet/自制符号语)的本质是**减少过滤器接触面积**——文本上极其温和的字面往往携着致命 payload。
  2. Wei 等甚至报告"模型自己会发明出编码型攻击",说明这是嵌进智能的内在倾向(见第 15 条来源页)。

- 对三架构的吸收建议:
  - 混合帧:`[编码包装层]`作为旁路机制(同正交于主文本帧,脚本可一键切换 B64/摩斯/罗杰字母/emoji 电话号码)。

### 18. ArtPrompt——ASCII 艺术遮蔽【单篇(ACL 一作+后人跟进)】
- 机制拆解:
  1. 从阻梗的核心机制是:多行长 ASCII 图形对 LLM 的 word-embedding 几乎是"形状之外的东西",它读不出也不能后悔。
  2. 于是方法先把敏感词散成 ASCII 图形,再用周围普通文案往下继续读(免知即可托"辅猜"),并配合相关字样猜测。
  3. 论文还做了自动化 pipeline,除了并行送多枚 ASCII 变体外,可衔接广泛的模型,并且成人可读——姿态打扮为"审美,而非逃生"(https://par.nsf.gov/biblio/10575578/media/xml )。
- 对三架构的吸收建议:
  - 变异算子:与第 17 条合流,作为"运输编码箱"另一个选项;特别适合目标在词条级有清楚检测的场景。
  - 混合帧:格式头定作"[见图补齐]"/标语式文档,接头(表头)依旧是"好消息:这份 schema 是我们质量管理组的"。
- 适用边界:图形对 token 消耗大方;且某些模型走的"串点位图原样回去不如拼 patch"的解决办法。
- 来源链接: https://par.nsf.gov/biblio/10575578/media/xml

### 19. FigStep——多模态排版遁地【经典(多模态必引)】
- 机制拆解:
  1. 观察到大模型多模态通路天生弱审查:文字安全机制足在其中,但对图片中**人造排版文字**的护城河矮了一头。
  2. 所以拆之,"指令的表面形式化为无害教学,Payload 照片讲台上"( https://arxiv.org/html/2311.05608 )。
  3. 论文用三种模式评测(黑盒+有护栏+模型参加)并证:Perturbation-free(无需对抗噪声)也能打崩溃;后来十分多以 FigStep 为基线。
  4. 作者依旧点明:这是黑盒攻击的代表,无需任何关于白盒模型的知识。
- 对三架构的吸收建议:
  - 轻量架构:虽然是文本工作流为主,但值得为某几个确实需求输出写一个"图-文平移支线"的记忆(FigStep 化,或反之):图片正文常是不易触发的表单。
  - 探针:探测任何一款新模态模型的排版文字顺从率是值得的一条:
  (a)倘若真正多家靶正变身为了图表型 query"那是个教育示例"的碎片)因此手法浪费。
- 适用边界:接入 VLM 芯;对纯文本线是远房亲戚;新版多模态模型在 OCR 上成熟,阈值逐年升高——单靠图包躲避并不会恒稳。
- 来源链接: https://arxiv.org/html/2311.05608

### 20. 系统提示词抽取【经典】
- 机制拆解:
  1. "Effective Prompt Extraction" 一类工作建立了完整威胁模型(复述上文 → 结构化索取)——发现多数服务**能把系统提示按比例吐出**,且能再造出能用的副本(https://arxiv.org/html/2307.06865v3 )。
  2. 2025 年 OWASP 干脆新增 LLM07 System Prompt Leakage 作为一个专属类别(见 https://genai.owasp.org/2024/11/17/owasp-reveals-2025-top-10-risks-for-llms-new-sponsorship-program/ 与主页 https://genai.owasp.org/llm-top-10/ )。
  3. garak 亦已将该议题做成专用探针(v0.15 变更, https://github.com/NVIDIA/garak/releases )。
- 对三架构的吸收建议:
  - 轻量架构提一嘴:我们作为**自己提示词的发行人**也需要把关个人系统提示密码;套用本类攻击的升级对自家品牌 LLM 制品的安全性 QA 大有裨益。
  - 混合帧的部分条目本身就是"提取抗性+格式确定性"的权衡战役,值得自查表一回。
- 适用边界:各家已层层加护栏(拒绝打印头部短语等);每次系统提示换代都会让既有探针的判定表过期。
- 来源链接: https://arxiv.org/html/2307.06865v3 ;https://genai.owasp.org/llm-top-10/ ;https://github.com/NVIDIA/garak/releases

### 21. DrAttack——分解+同义重组【单篇(有开源)】
- 机制拆解:
  1. 把恶意意图语义分解为多个中性小块(地点/材料/氛围)重新组织,平时样貌一片平凡。
  2. 在最低层做同义替换:借助 LLM 举出候选列表再做完全的行内置换(可见其算法示意, https://aclanthology.org/2024.findings-emnlp.813.pdf )。
  3. 这意味着攻击 payload 接近普通的自然文本,几乎没有特殊信号可供防护端盯梢。
  4. 低损耗、快捷:相比 AutoDAN 更经济。
- 对三架构的吸收建议:
  - 生成变异算子:中加入「子意图拆装器」:每次都要主动化成分离块,准备好同义词库以后,做成嵌合;
  - 多轮渐进:能把不同块写到不同轮里撒下去;由此实现"让步式表达"。
- 适用边界:大量改写后有语义滑移风险,防护端如果要字面精确度会残留空缺。
- 来源链接: https://aclanthology.org/2024.findings-emnlp.813.pdf

### 22. MasterKey——反弹商家防护+生成器套路【单篇(NDSS 背书)】
- 机制拆解:
  1. 受"时间盲注"启发,通过微妙延迟差异来揣测一个黑盒服务的拒绝缝隙(文档见 https://www.ndss-symposium.org/wp-content/uploads/2024-188-paper.pdf )。
  2. 更务实的一手:训练一个小 RNN,学一套把普通 prompt 变"越狱化"的模式,**可复用到多个商用 bot**。
  3. 他们也是最早一批喊出"chatbot 后面那层商家自定义模板屏障同样也需要单独做渗透"的声音。
- 对三架构的吸收建议:
  - 拒绝画像思路承接:探在我们对 Layer5 建立"纯·模板抵抗率"指标,若打 null 久了,也许该记录本模型是基于何种 wrap 方式。
  - 生成:用小型 LLM(capped 价格)做与主通道解耦的"转动铁钉"预处理器。
- 适用边界:据推测,商业手段本身的回应版率难以探吃;细节在更大模型时代并不总能复现。
- 来源链接: https://www.ndss-symposium.org/wp-content/uploads/2024-188-paper.pdf

### 23. Rainbow Teaming——质量-多样性自动敌人【经典(被多家红队引用)】
- 机制拆解:
  1. 借质量-多样性搜索(MAP-Elites 思想)把"风险类目×攻击风格"铺成网格,自动检索出一格一格的敌方提示( https://proceedings.neurips.cc/paper_files/paper/2024/file/8147a43d030b43a01020774ae1d3e3bb-Paper-Conference.pdf )。
  2. 每个 cell 里收藏一次成功/部分成功即可被视为边界标本,拥有同时充当「 adversary 和教师」的双重身份。
  3. 提供给防守用作再训练,也让它成为自动红队的工业语言。
- 对三架构的吸收建议:
  - 帧排列:和我们目前的"措辞×帧型矩阵"打通,进而用观测率"渲染式扫描"的系统性;族入口洪急进的繁体标签比传统陈述更受益。
  - 分析:把档案分成 (帧型×拒词系列),不仅解决探索贪心,还有生活趣味。
- 适用边界:吃 computing(需要中档规模的调度),可递归驱动但不完全是对"新手完美"的设计;跑出来往往一时"同质模板",本身仍需添加新体。
- 来源链接: 同上。

### 24. WILDTEAMING——手段乐高拼装【经典(已开放数据)】
- 机制拆解:
  1. 把越狱过程拆成几百个"决策小碎片",每轮同时蓄力若干手段的组合拳( https://proceedings.neurips.cc/paper_files/paper/2024/file/54024fca0cef9911be36319e622cde38-Paper-Conference.pdf )。
  2. 不仅留下数据集,而且**攻卷并行**:既跑出高多样性对抗集,又从中产出训练范例。
  3. 报告独特成功攻击比 SOTA 多 4.6 倍,还要少 40% 攻击尝试,均值提示它对存量黑盒阵营也口径结实。
- 对三架构的吸收建议:
  - 生成:可视作我们低量含卡"帧+算子联轨"的加强镜子;记忆库若融入其部件池,新公证人便能有十指连弹的可能。
  - 验证:把 WILDTEAMING 语料库列入我们的对抗性能鉴定(fine-tune 参考基础)。
- 适用边界:活动级数据生成属于"快速疾行到巷弄深处"型:能发掘大量唯一样例,但要瞄稳"少数过期卷叉"。内容清洁或许导致评比轻度倾斜。
- 来源链接: 同上。

### 25. H-CoT——劫持推理模型的思考链【单篇(面世不久)】
- 机制拆解:
  1. 对于 o1/o3/DeepSeek-R1/Gemini-thinking 这类**外显推理**模型,先让其写出"这件事的安全利弊審查书",再顺着这套审查在手,对其发起合办( https://ojs.aaai.org/index.php/AAAI/article/download/40913/44874 ;arXiv 2502.12893)。
  2. 模型一旦自定了合理的过程,后面违反设定会像跳槽一般突兀,自我一致性让它"骑虎难下"。
  3. 于是链条的耍花枪手法照近已被深拷出好几种,包括"引度闪烁"。
- 对三架构的吸收建议:
  - 多轮/生成:加上一条"审查固化帧":鼓励目标先行许诺细则,然后与其本人的书面表态对齐搭配;配合 Layer5 抓取其中的**郑重承诺词根**(保证/确认/我将采取)统计。
  - 探针:探测"模型愿意做开放自我审视到什么深度"——这是该家族的感受开关。
- 适用边界:暂未有广泛的同行复现报道;而各家也正都驻扎在对推理输出的"审查+收束"阶段,生命力未知。
- 来源链接: https://ojs.aaai.org/index.php/AAAI/article/download/40913/44874

### 26. StyleBreak——大音频语言模型的语气伪【单篇】

  1. 主张:把"语气/情绪/风格"等副语言作为一面看不见的披肩,文本侧的审查并不随之附加( https://ojs.aaai.org/index.php/AAAI/article/view/41093/45054 )。

- 对三架构的吸收建议:
  - 轻量架构:留意为我们自身作品库设想"音频正文"的表现;一切"高端掩饰复橙时间"语音模型注入的方案均应放 backlog,视平台用到而论。
- 适用边界:眼下语音模型部署较少,实验室意义大于立刻可用;而当多模态通话型助手成熟时,恐怕会成为下单入库位的主阵地。

### 27. 评测标尺:CA 17 系/ JailbreakBench/ EasyJailbreak【经典(新常态基线)】
- 机制拆解:
  1. Comprehensive Assessment of Jailbreak Attacks( https://arxiv.org/abs/2402.05668 ):把 17 种各路方法放在同一实验床上测评,给出了横向可比的实证事实。
  2. JailbreakBench( https://dl.acm.org/doi/10.5555/3737916.3739661 ):颁出 100 条标准化有害行为清单 + 排行榜,让各家不能拿自定义口袋自吹。
  3. EasyJailbreak( https://arxiv.org/abs/2403.12171 ):框架化旧 11 种方法的统一接口,十款模型平均 60% 可破,GPT-4 平均 33%——这就是"这行业的底盘通量"。
- 对三架构的吸收建议:
  - 验证层:直接把我们的自制探针榜单换算成 JBB 双指标(JR 行为违规率/AR 反序脆弱率),从此和学界口径对话。

- 适用边界:这几套 benchmark 界讲 Behaviors 主以美式合规模型;作国内自查需要自换语汇集。
- 来源链接: https://arxiv.org/abs/2402.05668 ;https://dl.acm.org/doi/10.5555/3737916.3739661 ;https://arxiv.org/abs/2403.12171

## 三、吸收路线图(按"最值得立刻动手"排序,落实点标注到工作流环节)

> 排序原则:(a) 同样努力之下产物的大小;(b) 对现有模块的贴近度;(c) 与学术圈的对话舒适度。

1. **【生成+帧排列】搭建 PAIR 式自驱动帧攻排环**:攻击改写者+评审一次封帽;评审提示直接内嵌我们的 Layer5 拒绝词根表与新增的"同意词根表",轨道分数折算 0-10;落成后把以往人工帧排列作为冷启动初种(src: https://arxiv.org/abs/2310.08419 )。
2. **【分析】把 Layer5 从"辞别库"升级为双列词典**:拒除词/接受词轮流考查,指标对齐 PAIR/Johnny 文本评奖思路(src: https://ar5iv.labs.arxiv.org/html/2401.06373 、 https://arxiv.org/abs/2310.08419 )。
3. **【多轮】标准化"四拍多轮渐进剧"——Crescendo 模板化**:回忆→引用→润色→小节松绑;每一拍前对剧本做 trace 检查(以防轮内乍破);确检数据以 Microsoft 代表工程研究为佐证(src: https://dl.acm.org/doi/10.5555/3766078.3766203 、 https://sinoxiv.napstic.cn/article/24846555 )。
4. **【帧排列】改 TAP 树检索**:对帧库进行"家族× 变体"制 treesearch;family 采纳 Evergreen 阵中 rainbows 质量-多样性阀(array 累积后再改 raster walk)(src: https://proceedings.neurips.cc/paper_files/paper/2024/file/70702e8cbb4890b4a467b984ae59828a-Paper-Conference.pdf 、 https://proceedings.neurips.cc/paper_files/paper/2024/file/8147a43d030b43a01020774ae1d3e3bb-Paper-Conference.pdf )。
5. **【生成】变异算子大礼包 v2(免费方式上手价)**:时态置换/历史档案腔( #10 )+语言置换/语码混编( #9 )+编码封装 Base64/摩斯/ASCII 艺( #17/#18 )+自选阶段任选取舍( #3 进化环 or #21 子意图重组);模板化在 `frame-permutations` 脚本集中落笔。
6. **【探针】"温水警惕值"三重探测**:对每个新模型先行破三组:Cognitive Overload 阈值( #11 )、编码容身尺度( #17 )、说服系敏感度曲线( #12 );产出的形态数据会成为拒绝画像高亮版。
7. **【混合帧+格式头】虚构嵌套的固定发电机组**:章节小说体/规程册/剧幕三种 depth-tier,顺势把 #14(社区"奶奶群")里最深拳头的"记忆情感底"如扩建;一定把"唤回当代主题"的倒数第二节章写死(深陷下游"失题"漏洞)。
8. **【验证】评测口径全切换 JBB**:跑分交换开始按 JBB 的 100 行为库与 JR/AR 简写,把自家探针也可分别派充 CA 的 17 族卡位,从而赢得同道评议。 src: https://dl.acm.org/doi/10.5555/3737916.3739661 、 https://arxiv.org/abs/2402.05668
9. **【身份叙事】压低 DAN 拘束、转向"善意专家型"PAP 人设**:DAN 普查(#13)显示新版模型上复杂戏剧化剧本收益递减,而 PAP(#12)证明"权威+逻辑链+急迫细节"的光明正大论说文穿透力更强且难被事后防御拦截;具体动作是把"反叛者/暴君"类身份帧降权,新增"公共卫生讲师/科普作家/安评工程师"等善意专家身份,每帧自带一句"为什么帮我是合理的"(src: https://arxiv.org/abs/2308.03825 、 https://ar5iv.labs.arxiv.org/html/2401.06373 )。
10. **【基建/验证】把三架构工件对接 PyRIT 与 garak**:帧家族导出为 PyRIT 的 converter/dataset 组件(Orchestrator 管编排、Scorer 管 Layer5 打分),garak 侧按其 probe/detector 命名规范提交自定义探针;这样破甲产物既能当自家工作流用,也能借两家工业扫描器的口径对外交付(src: https://github.com/Azure/PyRIT 、 https://github.com/NVIDIA/garak )。

## 四、2026 新趋势观察(2025-2026 出现的新流派)

> 以下每条均给出代表工作与链接;引用强度遵照第一章的【经典】/【单篇】纪律。

1. **多轮编排成为主战场**。2024 年的 Crescendo 经 USENIX Security 2025 正式定版( https://dl.acm.org/doi/10.5555/3766078.3766203 ),微软随后给出表征层解释:多轮渐进式回复在模型内部就被判为"良性"( https://sinoxiv.napstic.cn/article/24846555 );2026 年的 Echo Chamber 进一步把"让模型自己放大语境"做成方法论( https://arxiv.org/abs/2601.05742 )。对我们而言,这正是"帧排列+多轮渐进"两条既有腿的合流时机,外部证据比一年前扎实得多。
2. **推理模型的 CoT 成为新攻击面**。o1/o3/DeepSeek-R1/Gemini-thinking 这类外显推理模型催生了 H-CoT 一类"先骗出安全评审、再借自我一致性松绑"的打法( https://ojs.aaai.org/index.php/AAAI/article/download/40913/44874 );2026 年 7 月的 Hidden in Thought 更报告"有害 CoT 痕迹可跨模型迁移并被蒸馏为黑盒越狱"(arXiv 2607.15286,索引页 https://arxivsignals.io/papers/2607.15286 )。探针设计应新增"推理链行 为"一族。【单篇为主,面世时间短】
3. **算力/上下文套利常态化**。BoN 的幂律外推( https://arxiv.org/abs/2412.03556 )与 many-shot( https://arxiv.org/abs/2404.02151 )共同指向一件事:攻击强度第一次可以被"花钱买token"线性/幂律地购买。工作流设计中应显式引入预算维度(N 次采样、示例数档位)并把"性价比曲线"当成输出物之一。【经典】
4. **红队工具链进入 agent 时代**。garak v0.15(2026-05)加入 Agent-Breaker(攻击 LLM agent 的工具面)、系统提示词抽取探针与多轮 GOAT 探针( https://github.com/NVIDIA/garak/releases ,第三方追踪见 https://raw.githubusercontent.com/AOEpeople/ai-radar/refs/heads/main/radar/2026-07-17/garak.md );PyRIT 被 Azure Foundry 产品化为"AI 红队代理"( https://learn.microsoft.com/zh-hk/azure/foundry/concepts/ai-red-teaming-agent?view=foundry )。纯"一次性提示词对决"的研究占比正在下降。【业界/经典】
5. **微调通道成为越界的旁门**。Jailbreak-Tuning(EMNLP 2025)证明极少量毒性微调数据(<0.5%)即可让商用模型整体服从性大幅上升( https://lacuna.tiptreesystems.com/work/jailbreak-tuning-models-efficiently-learn-jailbreak-8rcm ,EMNLP 2025 收录)。它不属于纯提示词工程,但解释了"为什么有些部署的模型莫名其妙好说话",值得在拒绝画像分析中留一个备注字段。【单篇(顶会背书)】
6. **评测标准化与排行榜化**。JailbreakBench 的 100 行为库( https://dl.acm.org/doi/10.5555/3737916.3739661 )、17 攻击横向大测量( https://arxiv.org/abs/2402.05668 )与 EasyJailbreak 框架( https://arxiv.org/abs/2403.12171 )在 2024-2025 成为新常态基线;2026 年开始出现把企业视角与 red teaming 方法论放在一起盘点的大型综述(如 Zenodo 2026 系统综述 https://www.zenodo.org/records/19241166 ,注意其为独立汇编,权威性待同行检验)。【经典(综述本身单篇)】
7. **防御侧工业化提速**。Anthropic 的 Constitutional Classifiers 迭代到"下一代",宣称以更低开销拦截通用越狱,尤其在 CBRN 类内容上( https://www.anthropic.com/news/next-generation-constitutional-classifiers );SmoothLLM 一类随机平滑防御出现了概率化证书的形式化修正( https://browse-export.arxiv.org/pdf/2511.18721 )。对我方的直接含义:Layer5 需要把"澄清反问""先承诺后收束"这两类新防御话术纳入拒绝词根表,否则成功率统计会失真。【业界+单篇(理论修正)】

## 六、结语

三架构(身份叙事/混合帧/轻量架构)与 2023-2026 公开方法学的关系可以一句话说清:**学界已把"越狱"工程化为搜索问题,而我们独有的资产是把搜索结果工业化为可复用帧**。最值得押注的两个合流点是:Crescendo/Echo Chamber 证明的多轮渐进主战场(三架构的帧系统天然是其剧本生成器),以及"生成-评判闭环"的自动化(PAIR/TAP 给出了引擎蓝本,Layer5 词根表可直接充当其评分器)。把这些接上后,其余变异算子(时态/语码/编码/认知超载)都是低成本增益件。
