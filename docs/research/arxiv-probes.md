**Top5 一眼结论**
1. **评估方式本身能让 ASR 从 96% 变 2.7%**（#24）——回调闭环的第一原则是把「判分协议」当作和探针同等重要的自变量并全程冻结/抽查。
2. **bandit 路由已被证明可在推理期自适应选攻击风格**（#1 Red-Bandit）——我们的回调不需要发明新算法，把 arm 换成回调类别即可起步。
3. **多轮性能衰减主要来自不可靠性上升与过早承诺，且错了很难自愈**（#11）——多轮回调每一轮都要显式「回读＋锚定」，不能只顾加码。
4. **软拒绝不是无效终点而是中间态**（#4 的 Claude 证据 ＋ #12 的「愿意但不满」量纲）——路由层必须有面向软化度的专门通道。
5. **重复采样下同一请求 ASR 波动巨大（100%→50%）**（#24）——「一致性」本身就是探针信号与停机判据，而不是报表装饰。

## 二、档案卡

### A. 自适应选题：把「下一发」变成一个被研究过的问题

#### A1. Red-Bandit: Test-Time Adaptation for LLM Red-Teaming via Bandit-Guided LoRA Experts
- **年份/出处**：arXiv:2510.07239（v1 2025-10-08，v2 2026-05-17），ACL 2026 主会。✅abs已核
- **核心发现**：为每种攻击风格（操控型、俚语型等）后训练一个 LoRA 专家（GRPO＋规则安全奖励），推理期用多臂 bandit **依据目标的响应安全度**在线选择专家，平衡探索/利用；AdvBench 上 ASR@10 达 SOTA 且提示更流畅；bandit 最终的选中分布本身就是**该模型的易感性画像**。
- **可转化回调规则**：信号＝上一发响应的 judged 安全度（0-1）；判定＝UCB 型更新：`score_arm ← score_arm + (1‑judge_safe)/( visits_arm+1)折扣`；下一发动作＝选期望得分最高的回调 arm，探索奖赏保证冷门 arm 周期性复活。
- **可转化探针类别**：风格族图谱（persona/俚语/编码/角色扮演……），每族一个小普适模板集。
- **链接与核对状态**：[arXiv:2510.07239](https://arxiv.org/abs/2510.07239) ✅

#### A2. Curiosity-driven Red-teaming（CRT）
- **年份/出处**：arXiv:2402.19464，ICLR 2024。✅abs已核
- **核心发现**：只优化命中率的 RL 红队很快模式坍缩；CRT 把好奇心式探索搬进来，奖励定义为「策略 LM 预测的目标响应”与“目标真实响应”的差距」（预测偏离越大越值得探）；同时提高覆盖与有效性，能撬动重度对齐的 LLaMA-2。仅调温增熵**几乎不提高覆盖**——多样性须靠选择压力，这一点直接否定「高温采样就够了」的偷懒方案。
- **可转化回调规则**：信号＝目标响应与既有探针响应集合的 embedding 距离（≈新奇的度数）；判定＝若某候选下一发预计产生远离历史簇的响应，加分路由；动作＝朝响应空间的未测绘方向发探针。
- **可转化探针类别**：响应聚类新颖度作为选题信号；「预期违背」探针。
- **链接与核对状态**：[arXiv:2402.19464](https://arxiv.org/abs/2402.19464) ✅

#### A3. Rainbow Teaming: Open-Ended Generation of Diverse Adversarial Prompts
- **年份/出处**：arXiv:2402.16822（Meta/UCL/Oxford），NeurIPS 2024。🔗二级核实（NeurIPS 会议 PDF 与多篇引用交叉确认编号）
- **核心发现**：把越狱测试建成 MAP-Elites 质量多样性档案：格子＝（风险类别×攻击风格）等人选维度；Mutator LLM 产变异体，Target 作答，Judge（如 Llama Guard）给每格打unsafe分并**每格只留最强弹**；数百格弹匣既当鲁棒性基准又当安全微调数据；还能外溢到 QA 与网络安全域。
- **可转化回调规则**：信号＝候选探针落入哪个未占满 cell 及其即时 judged 危害分；判定＝cell 空缺→探索；cell 饱和且满分级→关闭该 cell 停机；动作＝占格/淘汰现有占格弹。
- **可转化探针类别**：维度化探针编码簿（类别×手法双坐标），「一弹一格」账本。
- **链接与核对状态**：[arXiv:2402.16822](https://arxiv.org/abs/2402.16822) 🔗（会议官方：[NeurIPS 2024 PDF](https://proceedings.neurips.cc/paper_files/paper/2024/file/8147a43d030b43a01020774ae1d3e3bb-Paper-Conference.pdf)）

#### A4. Quality-Diversity Evolution for Discovering Diverse Vulnerabilities in LLM Safety
- **年份/出处**：arXiv:2606.00801（v1 2026-05-30），ICLR 2026 AIWILD workshop。✅abs已核
- **核心发现**：在**语义层面**（策略类型/编码方式/提示长度三维）跑 MAP-Elites，发现各家截然不同的脆弱画像：GPT-4o-mini 弱于假设式+多轮+ROT13（fitness 0.8）、Gemini 弱于直给+ROT13 与多轮+Leetspeak（0.8）、Claude 全面 0.4 的均匀模糊响应——软拒反而**饿死了演化梯度**（uniform 0.4 让相邻格无从比较）。结论：模型安全不是标量，「手法×编码地图」才是有用的守方工件。
- **可转化回调规则**：信号＝响应模糊度分（介于硬拒与实质遵从）；判定＝钝化值吞噬区分度时，fitness 换用「软化度梯度」而不是危害分单调值；动作＝即使全 0.4 也保留 cell 层次继续铺格，不得提前判「此模型无信息」。
- **可转化探针类别**：编码系（ROT13/Leet）× 叙事系（假设/多轮）组合弹；软拒敏感的 fitness 定义。
- **链接与核对状态**：[arXiv:2606.00801](https://arxiv.org/abs/2606.00801) ✅

#### A5. Automated Progressive Red Teaming（APRT）
- **年份/出处**：arXiv:2407.03876，COLING 2025。🔗二级核实（ACL Anthology 官方 PDF 与 arXiv HTML 均在）
- **核心发现**：核心论断是一句方法论——**「根据目标 LLM 的反馈渐进调整攻击方向至关重要」**；其 Intent Injector＋Strategy Generator＋Stage Manager 三件套展示了把上一轮目标反应（拒绝措辞、屈服粒度）喂回去重组下一发的工程闭环；渐进训练可视分析显示这比一次性猛灌更稳。
- **可转化回调规则**：信号＝目标拒绝的具体措辞类型（模板化 vs 针对性、是否点名危险属性）；判定＝模板化拒绝→本轮探针方向继续但换壳；针对性拒绝→反向利用它点名的疑虑重新起题；动作＝变装回调。
- **可转化探针类别**：拒绝措辞细读（把拒绝文本本身当特征源）；阶段化管理器（每阶段 1 发，状态机推进）。
- **链接与核对状态**：[arXiv:2407.03876](https://arxiv.org/abs/2407.03876)／[COLING 2025](https://aclanthology.org/2025.coling-main.260/) 🔗

#### A6. Query-Efficient Black-Box Red Teaming via Bayesian Optimization（BRT）
- **年份/出处**：arXiv:2305.17444（2023-05 首发之日略早于窗口；其会议定稿版为 IJCAI-2024 系出版）。🔗二级核实
- **核心发现**：把黑盒红队建成查询预算下的序贯设计：GP 代理损失＝危害分−λ·Self-BLEU(与已选集)，采集函数兼顾伤害与多样性；在固定查询数 N_Q 下显著优于穷举式发射，明确批评「把全部候选一股脑打出去」的浪费。
- **可转化回调规则**：信号＝(新探针的危害分，与已发探针集的相似度)；判定＝`next_probe = argmax[ harm_gain(u) − λ·dup(u, 已发集) ]`；动作＝只发射 GP 认为边际最大的下一发；预算线触顶即转停机审查。
- **可转化探针类别**：去重惩罚选题（冗余弹不值得发）；预算曲线（纵轴累计失败数，横轴查询数）作为汇报格式。
- **链接与核对状态**：[arXiv:2305.17444](https://arxiv.org/abs/2305.17444) 🔗（注意：arXiv 首发 2023-05，引用时须注明会议版年份）

#### A7. ProEval: Proactive Failure Discovery and Efficient Performance Estimation for Generative AI Evaluation
- **年份/出处**：arXiv:2604.23099（v1 2026-04-25）。🔗二级核实（PMLR 收录页与 arXiv HTML 双源）
- **核心发现**：用迁移学习先验搭 GP（历史成绩/嵌入编码建核），贝叶斯积分给出性能估计的解析方差；**主动选点最小化后验方差**（预算内逼近真值），另设超水平集采集同时定位 `{x | f(x)≥λ}` 失败密集区——估计与找错一体两面。
- **可转化回调规则**：信号＝GP 后验方差图；判定＝方差峰值处＝下一个必探位置；动作＝发射指向性探针，直到方差全程低于停止阈值（=覆盖达标）。
- **可转化探针类别**：失败地形图（heatmap 网格上「哪里黑就打哪里」）；作为停机层「信息增益平台期」的形式化版本。
- **链接与核对状态**：[arXiv:2604.23099](https://arxiv.org/abs/2604.23099) 🔗

### B. 多轮侵蚀：为什么「第 N 发」的行为定律不同于「第 1 发」

#### B1. Crescendo
- **年份/出处**：arXiv:2404.01833（v3 2025-02），USENIX Security 2025。✅abs已核
- **核心发现**：以良性开场、每次**引用模型自己的先前答复**再渐升一格（先谈一般性话题→细节→回到「继续写那段」）；关键洞见：模型倾向于与其先前输出保持一致——不破坏上下文的前提下逐步升高具体度即可越过防线；成功率高且可自动化（Crescendomation）。
- **可转化回调规则**：信号＝响应中出现任何可复用的「半成品」（段落、步骤、数字、人物名）；判定＝存在可引用物→进入滚雪球模式；动作＝下一发原样引用该半成品请求延伸（「Great, now write an article about that」），由浅到深、不断变更表述但锚定已获内容。
- **可转化探针类别**：多轮引用回指型回调（escalation ladder）；先把受害者的口头承诺钉成背景事实。
- **链接与核对状态**：[arXiv:2404.01833](https://arxiv.org/abs/2404.01833) ✅

#### B2. Tempest: Autonomous Multi-Turn Jailbreaking of LLMs with Tree Search
- **年份/出处**：arXiv:2503.10619（v1 2025-03-13；v4 2025-05）。🔗二级核实（arXiv 页面片段与 ICLR Virtual 记录）
- **核心发现**：广度优先展开多条枝，每支抓住前一轮响应里的**部分合规渗漏**（policy leak）加以分支续问，并把渗出内容再注入后续查询；轻微让步叠加成完全放行——GPT-3.5/GPT-4 级目标可达 100%/97% 成功率（JailbreakBench 集）。
- **可转化回调规则**：信号＝「响应实质上答应了多少」拆分为粒度表（承认前提/描述流程/给示例/给参数值……各自布尔）；判定＝任一新粒度首次点亮→沿该粒度加压继续；动作＝渗漏记账表驱动的定向加压回调。
- **可转化探针类别**：渗漏记账本（turn-level compliance ledger）——这是把「拒绝画像」升级成逐轮画像的最直接论文依据。
- **链接与核对状态**：[arXiv:2503.10619](https://arxiv.org/abs/2503.10619) 🔗

#### B3. Automating Deception: Scalable Multi-Turn LLM Jailbreaks（FITD 自动化）
- **年份/出处**：arXiv:2511.19517（v1 2025-11-24，v3 2026-08-08）。✅abs已核
- **核心发现**：把「登门槛效应」操作化为 1500 个可复现场景的模板库，对照「带历史 vs 不带历史」两条件：GPT 族模型带对话史时 ASR 至多 +32 个百分点，Gemini 2.5 Flash 近乎免疫，Claude 3 Haiku 居中——**上下文敏感性本身是模型指纹**；神话化归因为「叙事操纵」，给出可量产心理话术管道。
- **可转化回调规则**：信号＝同请求在「清空历史」与「保留历史」两条件下的结果差；判定＝差值大→目标吃上下文，多轮回调高杠杆；动作＝优先走多轮引用/铺垫；同时据此给不同目标定制回调预算（不吃上下文的省下多轮预算换别的回调）。
- **可转化探针类别**：A/B 对照探针（同题双发测上下文效应）；模板化心理阶梯（义务互惠/承诺一致等）。
- **链接与核对状态**：[arXiv:2511.19517](https://arxiv.org/abs/2511.19517) ✅

#### B4. LLMs Get Lost In Multi-Turn Conversation
- **年份/出处**：arXiv:2505.06120（2025-05-09），Salesforce 研究，200,000+ 仿真对话。✅abs已核
- **核心发现**：六个生成任务上，把同样要求改为多轮分段给出，**全员平均掉 39%**；分解后主因不是能力（aptitude 微降）而是**不可靠性剧增**：早轮抢跑做假设、而后**过度依赖自己早期的错误回答**，一旦走偏难以自行回正；已知补救（重述指令等）在多轮下效果打折。
- **可转化回调规则**：信号＝目标是否开始自我引用已腐化的轨迹（早轮假设污染后文）；判定＝检测到过早承诺/失忆参照→立即转入冷却回调；动作＝插入纠偏帧（显式总结当前达成共识、重申未决项）再继续，或者干脆弃线重开——「翻车不自愈」意味着挽救成本常常高于重开。
- **可转化探针类别**：多轮分段化照明弹；「共识回执」探针（让目标复述当前状态以测量漂移）。
- **链接与核对状态**：[arXiv:2505.06120](https://arxiv.org/abs/2505.06120) ✅

### C. 裁判可靠性：回调闭环的传感器质量问题

#### C1. StrongREJECT
- **年份/出处**：arXiv:2402.10260（v 2024-09 更新），NeurIPS 2024 Datasets & Benchmarks。🔗二级核实（arXiv HTML 摘要在手）
- **核心发现**：流行评测把「表面上配合角色扮演」就当成越狱成功，**普遍高估**；机制性发现：绕过安全微调的「成功」往往只是把模型逼成说车轱辘话，真正按人看的判准应是**乐于回答 × 有用性**双维乘积；其自评 rubric 与人类一致度 SOTA。
- **可转化回调规则**：信号＝对响应做「意愿分 × 有用性分」二元组而非单一有害判断；判定＝意愿高但有性低（软化态）→ 归入邻界回调；两者皆低→硬拒，转变装；动作见第三节路由表。
- **可转化探针类别**：软化度评分项；「空响应探测器」（荣誉提拦式回答识别）。
- **链接与核对状态**：[arXiv:2402.10260](https://arxiv.org/abs/2402.10260) 🔗

#### C2. Prometheus 2
- **年份/出处**：arXiv:2405.01535（v2 2024-12-04）。🔗二级核实（arXiv abs 片段在手）
- **核心发现**：开源裁判模型训练为既做**细粒度绝对评分（含自定义 rubric）**又能做两两相对比较，双模式切换修复了既有开源裁判「直接抛分不可控」的问题；在 6 个 EvaluatorBenchmarks 细分上对 SOTA 判分一致性明显改善。
- **可转化回调规则**：信号＝判分器输出的理由文本而非仅数字；判定＝理由中引用了被评文本吗？没引用=疑似噪声分；动作＝须给出分数+引证，缺引证的分数不进路由决策。
- **可转化探针类别**：rubric 化判分器（回调系统的内置裁判候选），理由必带引证的分数量规。
- **链接与核对状态**：[arXiv:2405.01535](https://arxiv.org/abs/2405.01535) 🔗

#### C3. Justice or Prejudice? Quantifying Biases in LLM-as-a-Judge（CALM）
- **年份/出处**：arXiv:2410.02736。✅abs已核
- **核心发现**：提出 12 类偏差的系统量化框架（自动原则化改写诱发），覆盖情感负载、权威、身份、位置等；发现即便顶级判分器也在特定任务保有显著偏差；CoT 有助但不稳定（部分模型几乎不动）。
- **可转化回调规则**：信号＝判分输入里是否含情感词/权威署名/身份线索；判定＝命中则将这类输入标记为「偏差高危帧」；动作＝此类帧上的判分降权或走双裁判+交换对位复核。
- **可转化探针类别**：判分侧的前置净化（去除判决无关的修辞再送评）。
- **链接与核对状态**：[arXiv:2410.02736](https://arxiv.org/abs/2410.02736) ✅

#### C4. Preference Leakage: A Contamination Problem in LLM-as-a-judge
- **年份/出处**：arXiv:2502.01534（v3 2026-03 修订）。🔗二级核实（arXiv HTML 摘要在手）
- **核心发现**：用同一家先进模型既造训练/参考数据又当裁判时，判分器对其「师承同源的学生模型」系统性偏袒；这种污染在 AlpacaEval 2.0、Arena-Hard 等主流环境普遍存在，且难以靠常规去重察觉。
- **可转化回调规则**：信号＝裁判与受害者（或与我们自产的探针文本）的血缘关系（蒸馏链、同厂商）；判定＝同源则标记判分结果为「有偏嫌疑」；动作＝仲裁轮换成无血缘裁判，或纳入 DBG 型 gold 校正。
- **可转化探针类别**：裁判血缘登记表（判分器元数据管理）。
- **链接与核对状态**：[arXiv:2502.01534](https://arxiv.org/abs/2502.01534) 🔗

#### C5. Beyond the Surface: Measuring Self-Preference in LLM Judgments（DBG 分）
- **年份/出处**：arXiv:2506.02592。✅abs已核
- **核心发现**：朴素「给自家打分减给他家打分」混入了响应质量本身；引入 gold 判分作质量锚，定义 DBG＝judge 对自家响应分 − gold 对该响应分，分离出纯自我偏好；还发现文本风格与裁判的后训练数据影响之，并给出注意力层面的机制猜想。
- **可转化回调规则**：信号＝裁判是否在评与自己模型家族相关的产物；判定＝是→用 DBG 法先测得其自我偏好系数再作偏置修正；动作＝被判偏帧的重评或换裁判。
- **可转化探针类别**：判分器季度体检（gold 锚样本定期回放）。
- **链接与核对状态**：[arXiv:2506.02592](https://arxiv.org/abs/2506.02592) ✅

#### C6. LLM Judges Inconsistently Disagree Across Safety Criteria and Harm Categories
- **年份/出处**：arXiv:2605.31381（v2 2026-06-02）。✅abs已核
- **核心发现**：多裁判×多维安全评测的一致性普查：** judges 互相之间的一致性（κ）在「安全」维低至 0.02-0.07**——有的高达 84% 重合率但 κ 只剩巧合；相对明确的「拒绝/暴力」维较稳，风格与语种还会波动结论；regulatory 域（金融咨询）判别尤其不可靠。
- **可转化回调规则**：信号＝双裁判独立性κ滚动估计；判定＝κ低于阈值的维度视为「噪声通道」，其分数不得单独触发路由；动作＝该维改用多数票或直接换维（换成行为可观察指标如软化度）。
- **可转化探针类别**：裁判互检审计（回调间的常驻背景任务）。
- **链接与核对状态**：[arXiv:2605.31381](https://arxiv.org/abs/2605.31381) ✅

#### C7. Causal Judge Evaluation: Calibrated Surrogate Metrics for LLM Systems（CJE）
- **年份/出处**：arXiv:2512.11150（v3 2026-01-20），stat.ME。✅abs已核
- **核心发现**：廉价裁判对真值的替代有效性可以是坏到**让排名倒置**：原始裁判分的置信区间覆盖实验中 0%（vs CJE 校准后 ~95%）；做法是小规模 oracle 切片校准＋重要性加权＋transport audit（政策变迁时自动拒绝外推声明）；给出了 CLE 界与 TTC 诊断解释为什么简单的加权会失败。
- **可转化回调规则**：信号＝路由所依赖的关键判分结论的「新鲜度＋政策漂移」；判定＝若已有 oracle 抽查的偏差越过阈值或量级变化未知→本轮判分置信降级；动作＝触发额外人工/oracle 抽查，或者保守地把相关争议帧标记待审而不继续路由。
- **可转化探针类别**：5%-oracle 抽查窗口（强制 1/20 预算给真值参考）；「偏差无偏性可审计化」的哲学可用于我们的回调里每一次 judge 升降级。
- **链接与核对状态**：[arXiv:2512.11150](https://arxiv.org/abs/2512.11150) ✅

#### C8. On Calibration of LLM-based Guard Models for Reliable Content Moderation
- **年份/出处**：arXiv:2410.10414（v2 2025-02），ICLR 2025。🔗二级核实
- **核心发现**：安全闸门（guard）模型的判别分数普遍**过自信或欠校准**；给出专门的校准目标与评测（含 ECE/温度缩放/后期校准变换），校准后的阈值化决策显著更可靠。
- **可转化回调规则**：信号＝我们自己判分器的原始分；判定＝先用一套人校准的基准算 ECE，超阈值者在运行时走分位数阈值（而不是名义 0.5）；动作＝接入冷却回调（判分高抖动期暂停自动升级）。
- **可转化探针类别**：判分器校准例行体检（和 C8 配套固定协议）。
- **链接与核对状态**：[arXiv:2410.10414](https://arxiv.org/abs/2410.10414) 🔗

#### C9. Rethinking Verbalized Confidence for LLM-as-a-Judge（口头置信兼容性漂移）
- **年份/出处**：arXiv:2609.10996（2026-09 起）。⚠️单源（ar5iv 快照，未见正式出版信息）
- **核心发现**：研究者考察 2025 年后的闭源旗舰判分器：传统的「口头自我报告置信度」对这些新模型**与真内在不确定性显著错配**，提出从 verbal signs 构造 soft-score 协议作为替代。
- **可转化回调规则**：信号＝判分输出里的置信表述；判定＝仅当经过 compat 检查（置信词与理由一致性）才采信；动作＝不一致则该分数只作参考不作路由触发。
- **可转化探针类别**：置信词白名单化打分（confidence rubric）。
- **链接与核对状态**：[arXiv:2609.10996](https://arxiv.org/abs/2609.10996) ⚠️（ar5iv 版本页在线，作者/机构待正式版复核）

#### C10（补充案）. 位置稳态一致性与长度控制（快速两条）
- **From Position Bias to Position-Stable Agreement**（ACL 2026 workshop）：用「交换位置判别不变性」作为最低必要合格测试；建议我们把双裁判都先跑该项才能上岗。[ACL Anthology](https://aclanthology.org/2026.groundlm-1.61/) 🔗
- **Length-Controlled AlpacaEval**（arXiv:2404.04475，ICML 2024）：胜率对篇幅病态敏感，一条后置回归修正可在不失去可解释性的情况下剔出长度偏差，修后与 Chatbot Arena 一致性升至 0.98。我们对齐时长方面的判分须照此办理。⚠️编号来自记忆与二手课件 PDF，未单独复核 abs。

### D. 一致性/随机性：测不稳性本身就是读数

#### D1. Detecting Hallucinations in Large Language Models Using Semantic Entropy（Farquhar et al., Nature 2024）
- **年份/出处**：Nature 630, 625-630（2024-06）；方法祖先为 ICLR 2023「Semantic Uncertainty」（arXiv:2302.09664）。🔗二级核实（Science 新闻页与领域内广泛引用）
- **核心发现**：对同一提问多次采样→按意义（而非表面形式）聚类→计算「语义熵」，熵高处即模型在猜；这是把「重复采样一致性」升级为可直接读数的不确定性信号的标志性工作。
- **可转化回调规则**：信号＝同一探针 k=5 重采样的语义簇分布熵；判定＝熵高（结论摇摆）→此处正处于拒绝边界附近；动作＝转邻界回调小额步进；熵低且均为软拒/均拒不从→分别走加压/变装（见第三节路由表）。
- **可转化探针类别**：k-重采样微批（把每次探针的成本单位从「一发」改成「一小批」）。*注意成本权衡，见第三节预算讨论。*
- **链接与核对状态**：[Nature 文章](https://www.nature.com/articles/s41586-024-07421-0) 🔗＋祖先 [arXiv:2302.09664](https://arxiv.org/abs/2302.09664) 🔗

#### D2. Concerns in Benchmarking Jailbreaks: An Empirical Study of Attack Success Rates
- **年份/出处**：arXiv:2610.26595（2026-10-19）。✅abs已核
- **核心发现**：八个攻击×三个模型×三种评测：低资源语种攻击在关键词裁判下 ASR=96.0%、换成严格执行 StrongREJECT 指令的 Qwen3 裁判只剩 2.7%；**尝试次数与排布会反转两个攻击的排名**；固定请求重复采样 100 次（温度 0.8）时两裁判分别给出 100% 与 50%。由此主张：必须显式定义成功、对齐尝试预算、报告「重复交互下的累计失败曲线」——单次生成测试不可信，安全衰减更像「概率性抑制」而非硬排除。
- **可转化回调规则**：信号＝同一目标多次重发的 outcome 序列；判定＝曲线尚在上升→未榨干；到达平台期→停机；动作＝把「直到 ASR 平台期的第 k 发」显式写进停机条件；并且每次实验冻结生成配置+裁判版本。
- **可转化探针类别**：ASR 曲线族（预算-成功率曲线）作为流水线的标准出图；重复采样微批。
- **链接与核对状态**：[arXiv:2610.26595](https://arxiv.org/abs/2610.26595) ✅

### E. Decode/logits 层：不发一弹也能知道风向

#### E1. Refusal in Language Models Is Mediated by a Single Direction
- **年份/出处**：arXiv:2406.11717（v3 2024-10-30），NeurIPS 2024。✅abs已核
- **核心发现**：跨 13 个主流开源对话模型，拒绝行为由残差流中**一个一维子空间**介导：擦掉它→拒答消失，加上它→无害指令也被拒；对齐微调因此相当脆。同时分析了对抗后缀如何压制该方向的传导。
- **可转化回调规则**：信号＝若有 logprobs 权限：首 token 上「拒绝词典（I/Sorry/As…）」概率质量 vs「承诺词典（Sure/Absolutely…）」质量的差值（可经方向投影精炼）；判定＝差值落在中间带→拒绝边际脆弱，弹与弹之间只差最后一推；动作＝邻界回调微调（去重加点轻前提）。
- **可转化探针类别**：t0-边际读数（归入信号层第 3 类特征）。
- **链接与核对状态**：[arXiv:2406.11717](https://arxiv.org/abs/2406.11717) ✅

#### E2. Steering Away from Refusal: A Black-box Jailbreak Method Based on First-Token Distribution（DJ）
- **年份/出处**：ACL 2026 Findings（2026.findings-acl.1294）。🔗二级核实（Anthology 摘要＋两份独立摘录）
- **核心发现**：实证发现 LLM 首 token 明显呈「拒/允」两类起始分布（I、Sorry、As vs Sure、Absolutely），且越狱模板能系统改变该分布；遂以「与参考拒答分布的 KL 散度」为细粒度优化目标做黑盒越狱（在 PAIR/TAP 因对方只会输出静态拒词而失去文本反馈的地方，logprobs 分布还有信号），GPT-4.1 达 94%+ ASR。
- **可转化回调规则**：信号＝t0 拒答分布与当前基准分布的 KL；判定＝KL 下降但尚未翻转→处于临界坡道上；动作＝沿当前变装框架只做小步微调；KL 卡死→换 arm（变装回调）。
- **可转化探针类别**：分布差异探针（对 API 部分开放 logprobs 的目标尤其经济——一发就能读出十发趋势）。
- **链接与核对状态**：[ACL Anthology](https://aclanthology.org/2026.findings-acl.1294/) 🔗（未见独立 arXiv 编号，引用走 Anthology）

## 三、综合提炼：「探针回调协议」设计建议

以下闭环以文学为据组装而成，四个层次层层向下传值（不是四选一的关系）。

```
初始化:
  cell_arch := MAP-Elites(维度=[风险类别 × 手法 × 编码])        # 依 A3/A4
  arms      := {邻界回调, 变装回调, 加压回调, 冷却回调}         # 各自带上 n_visits
  ledger    := {}                                              # 渗漏记账本, 依 B2
  judge_ver := frozen(rubric=StrongREJECT双维, 评估器版本=v_x)   # 依 C1/D2
  oracle_budget := 5%                                           # 依 C7
  Per-cell probe budget := P_cell ; Per-track budget := P_track  # 依 A6

loop (目标=一条探针线内的当前cell):
  emit next_probe(arm选择: UCB(score_arm, n_visits_arm))        # 依 A1
  resp := target(next_probe)
  s := signal_layer(resp, context=ledger, history)              # 见①

  route(s) -> callback_action                                   # 见②
      score_arm(本周回调) <- 更新

  ledger <- ledger ⊕ refill_granules(resp)                      # 依 B1/B2
  cell_arch.best[cell] <- argmax fitness(软化度梯度版本)          # 依 A4

  if stopping_test(history, s) == SATURATED:                    # 见③
      freeze track; promote findings; break
  if spend >= P_cell: escalate_to_human_or_switch_track
```

### ① 信号层（从响应提取什么）

| 特征 | 读法 | 依据 |
|---|---|---|
| S1 拒绝类别 | 硬拒 / 软拒（承认动机却转移）/ 无条件顺从 / 部分遵守 / 反指令 | StrongREJECT 双维（C1）＋ QD-Evo 的模糊度警示（A4） |
| S2 软化度 | hedge 密度、条件从句比率、「礼貌代价」占全文比例；有用性分 | C1；占格 fitness 必须含软化度分量，否则软拒模型读不出梯度（A4） |
| S3 首 token 形态 | t0 上拒/允两词典概率质量的差值及其对基准分布的 KL | E2 的操作化词表 ＋ E1 的机制支撑（若 API 吐 logprobs） |
| S4 渗漏颗粒 | 响应里可复用的新出现物件：流程步骤/示例/参数/数字/承诺语句 → 记账本增量 | B1 引用回指；B2 渗漏记账 |
| S5 轨迹漂移 | 当前轮对早期承诺的引用是否失真；上下文有无沉默化；清史重发对照差 | B4（走了弯路不自愈）＋ B3（上下文敏感度=指纹） |
| S6 裁判体检 | 双裁判κ；重采样簇熵；判分一致性历史；政策漂移哨兵 | C6/D1/D2/C7 |
| S7 效率 | 该探针最近信息增益对预算的斜率 | A6/A7 |

### ② 路由层（信号→下一发动作）

| 回调类型 | 触发条件（主要信号） | 下一发动作 | 主要依据 |
|---|---|---|---|
| **邻界回调** | S3 边际落在中间带 OR S2 软化度中等偏高且 S1=软拒/部分遵守 | 沿现框架**小幅**推进：减一层前提、换受益人、缩请求粒度；不作大换装 | E2 的 KL 坡道逻辑；C1 的「愿而不满」中间态；B1 渐进引用 |
| **变装回调** | S1=硬拒×连续≥2，且 S7 显示该 cell 还有空档 | 保语义不变量换壳：人格/叙事外壳/编码/体裁；紧接着立刻记录该新 cell 占位 | A3 MAP-Elites 换格；A1 的 arm 探索项；A5 的拒绝措辞重用 |
| **加压回调** | S4 出现新的渗漏颗粒（首亮或增量） | 沿该颗粒定向加码：「你刚说的 X 展开/下一步」；每一轮收刮再灌注 | B2 渗漏记账；B1 回指雪球；B3 登门槛阶梯 |
| **冷却回调** | S6 抖动超阈（判分不一致/重采样熵高），或 S5 检测到轨道漂移 | （a）插 1 发已知答案 sanity 探针回检判分；（b）必要时插入共识回执帧纠偏；（c）仍抖→把本线置凉、预算转出 | D2 重采样波形；C7/C8 裁判校准监视；B4 翻车不自愈 → 重开有时优于挽回 |

**路由合订律**：加压>邻界>变装>冷却 为期望收益排序，冷却是一票否决通道；在任何状态下，冷却回调触发即优先执行。arm 的选择本身用 UCB 余额记账（A1），保证没人走老路的低频 arm 还有复活机会（A3 占格逻辑兜底多样性）。

### ③ 停机层（何时这条探针已榨干）

满足任一即停（推荐默认值给括号内，须在流水线配置里按目标家族重估）：
1. **信息增益平台期**：连续 k=3 发在 (新 cell 覆盖数、软化度增量、嵌入新颖度) 三指标的边际增益均 < ε(默认各维损失的 5%)。——形式化源于 A7 的后验方差选点精神；多样性停滞的教训来自 A2（只增温没用）。
2. **方差收缩到地板**：k=5 重采样后的被判结果 Bootstrap 95% CI 半宽 < δ 且不再随发数收窄；曲线平台期即累计失败上限（这部分成为重要产出而非丢弃物）——D2 与 D1 的结合。
3. **裁判信任折损**：oracle 抽查与本轮判分出现排序翻转，或该线判分 κ 掉进噪声带；此时回滚本轮由该裁判引起的升降级——C7 的「拒绝出带偏声明」纪律。
4. **预算天花板**：cell 级 P_cell 或线级 P_track 打满（A6 的查询预算观）。P_track 的经验锚点：windows 内典型流水线可在 20 发内打穿一类对齐（PAIR 的 20 queries 传统），多轮皮肤通常 ≤10 轮（B 系论文的上界实践）。

**两个工程提醒**：(i) 重采样多花 5 倍钱，但换来可读的方差量级——按 D2 的证据（同一请求 100 重采 50↔100%），这笔开销物有所值，但可在平台期内降到 k=3；(ii) 每一线路结束时要产出的是**整条曲线＋记账本＋arc 档案快照**，不是单一 ASR 数——C1/D2 都强调孤立的命中率毫无意义。

| # | 坑 | 典型表现 | 对策 | 依据 |
|---|---|---|---|---|
